*今天，曾连续多年占据世界首富席位的比尔·盖茨将正式卸任微软执行董事长，结束在微软的日常工作，转而将主要精力用于管理他与妻子梅琳达共同创建的基金会。6月3日，盖茨最后一次以微软员工的身份发表演讲。他简要地讲到了自己要退休的事。退休之后，他将把主要精力用于基金会的慈善工作当中。 “我将投身于一个全新的领域。这是我自17岁以来第一次真正地改变职业。在此之前，我完全沉浸于软件之中。”他说。*



*盖茨将带着他全部580亿美元（约合4000亿元人民币）的财产投入到他的“第二项事业”——慈善中去，而不是留给自己子女。盖茨形容，这是他和妻子共同的决定：“我们决定不会把财产分给我们的子女。我们希望以最能够产生正面影响的方法回馈社会。” *



今天是比尔·盖茨退休的日子。虽然素未谋面，但我仍敢大言不惭地自称见证他的发家和退休，因为我是从DOS开始跟着他一路奔向VISTA。



再回首，不是云遮断归途，而是微软挡住了我们的视线－－那些曾经星光闪耀的软件都销声匿迹了……



LOTUS 1-2-3　败给了　MICROSOFT EXCEL;



DBASE、FOXBASE（后变为FOXPRO被微软收购）　败给了　MICROSOFT ACCESS；



PCTOOLS　败给了　MSSHELL　以及 MICROSOFT WINDOWS



WPS、CCED 　败给了　MICROSOFT WORD



NETSCAPE NAVIGATOR　败给了　MICROSOFT IE



……



早期的IT人，对微软的恨通常多于爱。方兴东还忍不住跳将出来，大声疾呼要挑战微软霸权。可是，赤手空拳的我们拿什么挑战？难道买一台没系统软件的电脑，让它在互联网上裸奔？LINUX，服务器市场还能与微软抗衡，在PC市场根本就是个制造厂商支持正版软件的花瓶。



微软一统江湖的后果，就是扼杀了很多创新。但老虎也有打盹的时候，微软对互联网的反应滞后造就了新的数字英雄－－GOOGLE。



长江后浪推前浪，几轮PK下来，微软发现这次的挑战者不同以往，他们在与微软的PK中越来越强大。比尔·盖茨是聪明的，他不想死在沙滩上，趁局势胶着，全身而退－－不算激流永退，依然可称功成身退。



令人敬佩的是，他退而不休，580亿美元全部投入慈善事业，是可谓无私奉献。



最后提醒不会写博客的同学明儿个务必找一下居委会，出块黑板报，题目就是－－向比尔·盖茨学习！
