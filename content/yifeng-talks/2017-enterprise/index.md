《就算老公一分钱股份都没拿到……》刷爆了IT行业的朋友圈。简言之，就是CTO的老婆吐槽CEO如何之抠，老公作为“公司第2名员工”（他又说是联合创始人）拼死拼活地干了7年，没拿到一分钱的股权。



浏览完后，我加了个评语“花7年时间认清一个人，时间有点长”，也转了朋友圈。



在我看来，CTO方固然是一面之辞不可全信，但是CEO竟然没有发现CTO的负面情绪，没有意识到自己最初的股权结构设计中埋下了一个不定时炸弹，实在难辞其咎。



至我撰写本文时，不少公众号都紧追热点抛出了评论文章，各位有兴趣自己去搜索来看。



综合多方信息，我认为剧情没有很大的反转：



1. CTO干了7年，没有一分钱的股权是事实。
2. CEO有一个独资公司，也是事实。
3. CEO曾经在知乎上发表过创业公司如何“忽悠”技术合伙人的帖子，更是事实。



矛盾的本质在于，CTO把自己看成了联合创始人，而在CEO心目中，CTO不过是我“忽悠”来的一个打工仔。我相信CEO肯定拍过胸脯（我承认我也拍过），来吧，跟着我干，绝对有前途，到时候大块吃肉，大碗喝酒。苟富贵无相忘！



所以，CEO给CTO发一份工资，有一次甚至给了上百万的分红，他觉得没亏待兄弟。如果CTO只是个打工仔，那的确是没亏待。



问题来了，CTO拼了命跟CEO打江山，到头来发现江山还是你CEO一个人的，金山银山跟我没有一分钱的关系！说好的苟富贵无相忘呢？CTO觉得很委屈，也可以理解。



有人爆料CTO创业前几年贡献巨大，而后几年个人生产力没有跟上公司的发展，CEO并没有抛弃他，还“养”他。呵呵，这位CEO不但没有设计好股权结构，而且在人事管理上给自己挖坑，错上加错。



我的观点表述完了，咱们来点实际的，谈谈初创企业的股权结构设计。



前两年我看了一本书《切蛋糕——创业公司如何确立动态股权分配机制》，深受启发。



在传统的合伙观念里，合伙各方都习惯按出资比例来决定股权比例。我说的合伙各方，不仅投资，而且参与公司经营。谁出的现金多，谁的股份就多。



当公司业务启动后，我们会发现合伙各方对公司的贡献度实际是不一样的，客观上本来就如此，主观上更不用说了——每个人都会高估自己对公司的贡献。最糟糕的是，初创企业现金不足，合伙各方通常不拿工资或只拿一点生活费。



帐面上没钱的时候，大家都没声音。一旦有了利润或有投资要进来，这时兄弟情谊就面临着严峻的考验。**真格基金合伙人徐小平说得好：不要用兄弟情谊追求共同利益，要用共同利益追求兄弟情谊。**



因此，初创企业引入“动态股权分配机制”，或不失为一种很好的解决方案。我想我应该会在我的下一个项目中，尝试这个方案。



我先说一个假想的案例，案例基本情况如下：



- Ａ销售，Ｂ技术，Ｃ运营，三个人，打算合伙创建一个企业。
- 创建企业之前，各人的月收入：Ａ10000元，Ｂ15000元，C8000元
- Ａ打算投资现金50万，正好是公司一年的开销。B和C没钱。
- 在公司没有可分配的盈利或者没有投资进来前，三个人都不打算从企业中领取工资。
- 三人都会在公司全职工作，一年内不离开。



1. 启动时间点：建立一个“动态股权比例”基金池，A投入现金按4倍计算，故池子里面有200万（注意看后面的要点3）。
2. 第1个月结束：大家都不领工资，每人的月工资按2倍算，投入基金池。这时基金池里有 200+2+3+1.6=206.6万。
3. ……依次类推……
4. 第12个月结束：基金池里有 200+24+36+19.2=279.2万。股权结构A占80%，B占13%，C占7%。



虽然这是个假想案例，但是大家可以看到“动态股权分配机制”的运行结果：合伙办企业，不管最后是输是赢，出钱出力占大股，没钱出力占小股，给了各方一个说法。B和C在第一个月结束，股权比例都少得可怜，可是其精神意义重大。



“动态股权分配机制”的几个要点：



1. 适合初创企业，合伙人多半有时间没钱。
2. “动态股权比例”基金池仅用于计算股权比例，里面的绝对数不代表公司估值。
3. 公司日常需要开销的现金价值最大，所以投入基金池时放大４倍。注意，不开销的现金放在边上，不能投入基金池。上面我提出的假想案例为简化计算，直接把Ａ的50万投入了基金池，实际应该按月投入。
4. 合伙人应该领而未领的工资（与市场行情接轨），放大２倍投入基金池。合伙人放弃了外部机会参与创业，理应得到比打工更好的回报。不允许合伙人领了工资再投入现金到基金池。要是合伙人领工资，说明他没钱，没钱还投什么钱？



假如《就算老公一分钱股份都没拿到……》中的CEO，在公司创立之初，就借鉴“动态股权分配机制”的思路，我相信他今天也不会焦头烂额。



**一分钱的股份，给或不给，怎么给，从一开始就得有一个说法。耍小聪明，打太极拳，谈兄弟情谊，全是扯淡！**
